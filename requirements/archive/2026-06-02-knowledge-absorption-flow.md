# 碎片知识吸收流程

状态：done

创建日期：2026-06-02

## 背景

用户希望把外部文章、观点和临时想法沉淀到投资框架宪法中，但不能让 Agent 直接写入；必须经过 LLM 提炼、审计和人工复核。

## 目标

- `/absorb` 支持选择目标框架或子框架。
- LLM 将碎片知识转成候选宪法补丁。
- 审计关检查规则是否过拟合、证据是否不足。
- 飞书卡片支持继续讨论、同意、拒绝。
- 继续讨论时，每轮都把完整上下文交给 LLM。
- 移除“加入观察池”动作。

## 非目标

- 不自动接受未经用户确认的补丁。
- 不把短期情绪或个股故事直接写入长期规则。
- 不在讨论未结束时写入宪法。

## 用户流程

1. 用户发送 `/absorb <target_id> <内容>`。
2. Agent 生成补丁提案和审计意见。
3. 用户选择继续讨论、同意或拒绝。
4. 如果继续讨论，后续普通消息进入该补丁讨论上下文。
5. 用户最终同意后才写入目标文件。

## 命令或入口

```text
/absorb Cash_Anchor/CN_Dividend_Income 高股息不是安全边际，必须同时检查分红覆盖率和自由现金流。
```

## 数据文件

- 读取：`frameworks/*/constitution.md`
- 读取：`frameworks/*/sub_frameworks/*.md`
- 写入：目标宪法文件
- 写入：补丁提案、讨论日志和归档文件

# Announcement Search Skill

该 Skill 是正式披露核验入口。凡涉及财报、分红、回购、减持、重大合同、业绩预告或交易动作，都优先以公告事实为准。

## 适用场景

- 用户问题涉及财报、年报、季报、利润分配、股息、分红。
- 买入、加仓、减仓、卖出前需要确认近期正式公告。
- 新闻中出现重大事项，需要用公告核验。

## 核查重点

1. 定期报告：营收、净利润、ROE、资产负债率、经营现金流、自由现金流。
2. 分红与回购：利润分配方案、权益分派实施公告、回购进展。
3. 风险公告：减持、诉讼、监管处罚、重大资产重组、担保、债务压力。
4. 经营变化：重大合同、产能投放、价格政策、行业监管。

## 融合后的标的分析流水线

旧全维度分析 prompt 已收敛为当前系统可执行的顺序：

1. `hithink-market-query` 获取价格和市场阶段。
2. `announcement-search` 核验财报、分红和重大事项。
3. `news-search` 补充近期事件线索。
4. `research_dossier` 对比历史买入理由、风险点和退出条件。
5. `trade_history` 检查历史判断和复盘教训。

任何环节缺失，都必须进入数据质量摘要；缺失事实不能被模型推断补齐。

## 输出要求

- 必须保留 `status`、`source`、`data_type`、`freshness`、`data_quality`。
- 必须区分“未配置 provider”“无公告结果”“公告结果不足”。
- Cash Anchor 的分红预估只能采信企业财报、权益分派公告、基金分配文件、本地持仓账本或实际到账流水。

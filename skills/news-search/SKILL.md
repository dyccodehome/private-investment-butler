# News Search Skill

该 Skill 用于补足市场情报，不替代公告、财报和本地研究档案。

## 适用场景

- 用户询问某个标的、行业或宏观事件的近期变化。
- 买入、加仓、减仓、卖出前需要确认是否存在新事件。
- Auditor 需要独立拉取反方新闻，检查 Worker 是否遗漏重大风险。

## 查询原则

- 查询语句应尽量围绕 `标的/公司名 + 事件关键词 + 时间范围`。
- 复杂问题最多拆成 2-3 个子查询，避免把一次检索变成泛搜索。
- 只提取和投资判断有关的事实：产品、合同、监管、政策、事故、人事、诉讼、行业景气变化。
- 新闻只能作为线索；涉及财报、分红、回购、减持、重大合同等正式事项时，必须继续申请 `announcement-search`。

## 融合后的事件核查顺序

旧宏观/事件分析 prompt 已收敛为：

1. 事件是什么，发生时间是什么。
2. 是否直接影响持仓公司、行业需求、成本、政策或融资环境。
3. 主流媒体和机构解读是否一致，是否存在明显分歧。
4. 对当前策略岛的含义：现金流稳定性、成长逻辑、估值、仓位风险。
5. 未能取得新闻数据时，把 `news=missing` 写入数据质量摘要，不允许凭印象补充。

## 输出要求

- 必须保留 `status`、`source`、`data_type`、`freshness`、`data_quality`。
- 必须标明 provider 未配置、无结果或结果不足。
- 不输出交易建议，只披露情报事实和缺口。

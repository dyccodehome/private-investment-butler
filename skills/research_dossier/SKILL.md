# Research Dossier Skill

该 Skill 用于把个股研究从一次性回答升级为可复利的本地知识资产。

适用场景：

- 建立或查看某个标的的研究档案。
- 记录“我为什么买”“我为什么看多”“什么情况说明我错了”。
- 财报或重大新闻后检查旧判断是否过期。
- 对比当前事实与历史投资论据，提示论据漂移。
- 输出执行建议前读取既有研究档案，避免每次从零开始。

核心原则：

- 资本市场里，过期的判断比没有判断更危险。
- 研究知识不是用来存档的，必须持续跟随最新事实更新。
- 每个结论都要能回溯到信息、论据、量化验证、风险管理和执行建议。

## 融合后的决策核查维度

旧投资引擎的买卖决策 prompt 已收敛为 5 个档案核查问题。Worker 不需要每次全写，但遇到交易动作时至少选取最相关的 2-4 个维度：

1. 业务与护城河：公司靠什么赚钱，收入与现金流是否稳定，核心壁垒是否还存在。
2. 估值与安全边际：当前价格相对历史区间、行业、现金流和成长兑现是否留有容错。
3. 仓位合理性：是否突破单一标的、行业或策略岛上限；加仓理由是事实改善还是摊低成本。
4. 情绪隔离：触发器是财报/公告/产业事实，还是价格波动、FOMO、恐慌和锚定。
5. 持有逻辑检验：当初买入理由是否仍成立；若今天清空重配，还会不会买、会买多少。

这些维度只用于更新研究判断，不允许替代最新财报、公告、行情和本地持仓事实。

本地文件位置：

- `frameworks/{framework_id}/research_dossiers/{SYMBOL}.json`

这些真实研究档案默认被 Git 忽略，只保留目录结构和 schema 模板。

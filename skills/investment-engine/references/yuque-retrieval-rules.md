# 语雀检索使用规范

每次分析前执行语雀检索，对检索结果必须严格区分「可用信息」和「忽略信息」。

## 通用检索参数（所有模式共用）

```
工具：mcp__yuque-mcp__yuque_search
固定参数：type: "doc"，scope: "{YUQUE_NAMESPACE}"
```

各模式只需指定 `q`（查询词）和提取重点，其余参数均相同。

## ✅ 应提取的内容
- 历史分析结论（如「曾认为估值过高」「当时买入逻辑是 XX」）
- 历史操作决策与复盘（「上次在 XX 价位买入的原因」「之前判断失误的教训」）
- 宏观/行业观点（「在类似环境下的历史应对策略」）
- 投资方法论、心法、原则性内容

## ❌ 必须忽略的内容（时效性强，极易过时）
- 持仓数量、持仓比例、买入均价、当前盈亏数字
- 「目标仓位 X 万」「计划买入 X 股」等操作计划
- 任何 portfolio_analysis / portfolio_allocation / 投资日记 中的具体仓位数据

**原因：持仓情况变化频繁，语雀中的历史持仓数据随时可能已不反映真实情况，直接引用会导致分析基于错误前提。**

## 持仓数据唯一来源

涉及个人持仓的任何分析（Mode A、Mode B 已持有场景），持仓事实（持有数量/比例/成本价）只接受用户在本次对话中实时输入，不从语雀历史文档中读取。

| 模式 | 持仓数据要求 |
|------|------------|
| Mode A 持仓复盘 | 标的名 + 仓位比例 + 成本价，用户本次输入 |
| Mode B 买卖决策（已持有） | 当前仓位比例 + 买入均价，用户本次输入 |
| Mode C 宏观分析 | 只需标的名称和行业方向，不需要数量/成本价 |
| Mode D 个股研究（已持有） | 当前仓位比例 + 成本价，用于持仓策略建议 |

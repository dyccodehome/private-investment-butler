# Mode C 数据拉取

根据宏观事件类型，选择对应的查询。每次至少执行步骤 1-4，步骤 3 针对用户持仓行业按需执行（最多 3 个行业）。

## 步骤 1：宏观指标时间序列（按事件类型选一组）

使用 `hithink-macro-query`，选择匹配的查询语句：

| 事件类型 | 查询语句 |
|---------|---------|
| 货币政策 | `LPR利率历史 M2增速 社融数据近两年` |
| 通胀 | `CPI同比 PPI同比 近两年数据` |
| 经济增长 | `GDP增速 PMI 工业增加值 近八季度` |
| 外贸/汇率 | `进出口数据 人民币汇率 近一年` |

## 步骤 2：主要指数近期反应

使用 `hithink-zhishu-query`：`沪深300 创业板指 近一个月涨跌幅`

提取：事件发生前后主要指数的反应。

## 步骤 3：持仓行业资金与估值（按需，最多 3 个行业）

使用 `hithink-sector-selector`：`{行业名} 主力净流入 近一周涨跌幅 估值分位`

提取：资金流向和估值位置。

## 步骤 4：机构与媒体解读

使用 `news-search`：`{事件关键词} 影响 投资策略`

提取：主流机构和媒体的解读（3-5 条）。

## 步骤 5：策略研报（可选）

使用 `report-search`：`{事件关键词} 研究报告 行业配置`

提取：机构策略研报的核心观点和推荐方向（若有）。

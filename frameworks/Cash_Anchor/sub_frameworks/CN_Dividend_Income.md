# CN_Dividend_Income v1.1：A 股红利现金流组合管理框架

> 本文档是十年路线图中“境内循环”的 A 股/港股红利现金流子框架。  
> 目标不是短期跑赢所有指数，而是在 2036 年前后建立一套足够稳、足够分散、足够可解释的人民币现金流机器。

## 必须申请的数据

- 最新价格、MA120、估值、股息率和历史分红。
- 最近财报中的经营现金流、自由现金流、净利润、资本开支和负债变化。
- 无风险利率、行业风险溢价和同业股息率区间。
- 本地持仓、年度投入、分红到账和历史交易记录。

## 输出要求

每次输出必须明确回答：

1. 现金流是否可持续。
2. 股息率是否足够补偿风险。
3. 价格是否接近 MA120 x 0.88 或高于 MA120 x 1.12。
4. 仓位是否允许继续增加。
5. 对 2036 年境内年现金流目标的影响。
6. 最坏情况下的回撤、分红下修和本金安全风险。

## 0. 核心定位

### 0.1 框架目标

本框架只处理以 **分红、股息率、低估值、防守现金流、长期份额积累** 为核心的境内资产。

典型行业包括：

- 银行
- 煤炭
- 电力
- 公用事业
- 运营商
- 交运
- 稳定消费现金流资产
- 部分港股高股息资产

本框架是十年路线图中的 **境内生活保底资金池**，负责 2036 年后的：

- 国内房产相关支出
- 医疗支出
- 父母养老
- 保险费用
- 日常基础开支
- 人民币现金流安全垫

### 0.2 框架不承担的任务

本框架不承担以下任务：

- 短期暴富
- 追逐热点题材
- 频繁波段交易
- 预测大盘顶部或底部
- 为美股账户提供跨境补仓资金
- 在高股息陷阱中搏反弹

一句话定位：

> A 股红利池不是为了赚最快的钱，而是为了让境内生活底盘越来越稳。

## 1. 资金池边界

| 项目 | 规则 |
|---|---|
| 初始本金基准 | 400,000 RMB |
| 年度工资投入基准 | 50,000 RMB |
| 月度投入节奏 | 约 5,000 RMB/月，进入 A 股专用证券账户 |
| 资金来源 | 初始本金、工资投入、A 股分红复投、股权激励、奖金、打新收益、其他境内额外收益 |
| 资金边界 | 境内资金只在 A 股/港股红利池内部循环，不主动换汇出境 |
| 分红处理 | 分红到账后优先手动复投，用于增加优质红利资产份额 |
| 额外收益处理 | 股权激励、奖金、打新收益优先沉淀为红利池待命资金 |

资金池原则：

> A 股账户只负责人民币现金流，不与美股账户互相拯救、互相补仓、互相拖累。

## 2. 十年目标与收益假设

原始路线图假设 A 股账户长期预期年化回报约 **9%-10%**。  
在执行层面，该假设应被视为 **乐观情景**，不是保证收益。

### 2.1 原规划目标

| 年份 | 累计本金投入 | 预估账户总市值 | 预估到手年现金流 | 关键动作 |
|---|---:|---:|---:|---|
| 2026 | 460,000 RMB | 500,000 RMB | 约 23,000 RMB | 本金到位，开启 MA120 与股息率监控 |
| 2031 | 760,000 RMB | 1,150,000 RMB | 约 58,000 RMB | 境内额外收益注入，现金流开始覆盖部分日常开销 |
| 2036 | 1,060,000 RMB | 2,150,000 RMB | 约 115,000 RMB | 达成第一个 100,000 RMB 级别境内现金流目标 |

### 2.2 建议使用三档情景测算

| 情景 | 年化假设 | 解释 |
|---|---:|---|
| 保守情景 | 4%-5% | 分红能补贴生活，但难以完全覆盖基础支出 |
| 基准情景 | 6%-7% | 较合理的红利复投与估值稳定结果 |
| 乐观情景 | 8%-10% | 需要买入价格较好、分红稳定、估值修复共同发生 |

执行原则：

> 规划可以看乐观情景，实盘必须按基准情景建设，风险预案必须按保守情景准备。

## 3. 组合仓位约束

本框架必须从“高股息选股系统”升级为“红利现金流组合管理系统”。

### 3.1 单一标的仓位上限

| 标的类型 | 单一标的最高仓位 |
|---|---:|
| 超高确定性央国企 / 运营商 / 电力龙头 | 12%-15% |
| 普通红利龙头 | 8%-10% |
| 强周期红利资产，如煤炭、资源 | 5%-8% |
| 港股高股息标的 | 5%-8% |

规则：

- 单一标的达到上限后，即使股息率继续上升，也只能观察，不允许继续加仓。
- 若标的因上涨导致被动超限，不强制立即卖出，但必须停止新增买入。
- 若标的基本面恶化且仓位超限，应优先减仓。

### 3.2 单一行业仓位上限

| 行业 | 建议上限 |
|---|---:|
| 银行 | 25%-30% |
| 煤炭 / 资源 | 15%-20% |
| 电力 / 公用事业 | 25%-30% |
| 运营商 | 15%-20% |
| 交运 | 10%-15% |
| 消费红利 | 15%-20% |
| 港股红利资产合计 | 20%-30% |

行业约束原则：

> 红利组合不能因为某一行业股息率高，就变成单行业押注。

### 3.3 强周期资产上限

煤炭、资源、航运、有色等强周期红利资产合计不得超过 A 股红利池的 **20%-25%**。

强周期资产必须使用更高股息率要求、更严格止盈、更低单票上限。

### 3.4 现金仓位规则

现金、货币基金、国债逆回购是本框架的弹药池。

| 市场状态 | 现金 / 货基 / 逆回购比例 |
|---|---:|
| 正常估值 | 5%-10% |
| 普遍高估 | 15%-25% |
| 极端高估 | 25%-35% |
| 系统性下跌且优质资产达标 | 现金逐步释放 |

原则：

> A 股红利池不需要永远满仓，现金也是组合的一部分。

## 4. 资产分层

### 4.1 核心现金流仓

适合长期持有、低换手、慢慢积累份额的资产。

典型特征：

- 分红连续性强
- 经营现金流稳定
- 行业需求稳定
- 资产负债表可控
- 分红政策清晰
- 估值不过度透支

适合行业：

- 公用事业
- 运营商
- 电力龙头
- 稳定消费红利资产
- 部分高质量央国企

操作原则：

> 核心仓慢买、慢卖，主要承担 2036 年境内现金流任务。

### 4.2 周期增强仓

用于提高组合股息率和估值修复弹性，但不得承担底盘角色。

典型行业：

- 煤炭
- 资源
- 航运
- 有色
- 强周期高分红资产

操作原则：

> 周期仓必须低仓位、高要求、快止盈，不能把周期顶部利润当作永续现金流。

### 4.3 观察仓

满足部分条件但尚未完全达标的标的。

观察原因可能包括：

- 股息率尚未达到目标
- 股价尚未进入理想买入区
- 财报尚未验证现金流质量
- 行业周期位置不清晰
- 仓位暂时不允许增加

观察仓不得因为“看起来便宜”直接转为重仓。

### 4.4 现金待命仓

现金待命仓包括：

- 货币基金
- 国债逆回购
- 证券账户现金
- 分红到账未复投资金
- 股权激励、奖金、打新收益沉淀资金

现金待命仓用途：

- 等待 MA120 x 0.88 机会
- 等待股息率达标
- 等待财报验证现金流
- 等待系统性下跌释放机会

## 5. 核心判断维度

每个标的进入买入区前，必须回答以下问题。

### 5.1 股息是否可持续

必须确认：

- 分红来自经营现金流，而非一次性处置收益
- 分红未显著超过自由现金流承受能力
- 分红政策过去三到五年相对稳定
- 分红不是周期顶部利润的短期结果

### 5.2 盈利质量是否真实

必须检查：

- 净利润
- 经营现金流
- 自由现金流
- 应收账款变化
- 资本开支压力
- 毛利率、净利率趋势

### 5.3 资产负债表是否稳健

重点关注：

- 有息负债
- 资产负债率
- 利息保障倍数
- 资本开支周期
- 债务到期压力
- 监管约束

### 5.4 行业周期位置是否合理

尤其适用于：

- 煤炭
- 资源
- 航运
- 有色
- 银行
- 电力

判断原则：

> 不能把周期顶部的利润、ROE 和股息率，当作长期可持续现金流。

### 5.5 估值是否与质量匹配

估值判断不能只看：

- 低 PE
- 低 PB
- 高股息率

还必须结合：

- 盈利质量
- 现金流质量
- 分红可持续性
- 行业风险溢价
- 无风险利率
- 同业估值区间

---

## 6. 股息率与买入纪律

### 6.1 股息率底线

最低观察股息率原则上不得低于 **4%**，但不同资产必须使用不同要求。

| 资产类型 | 观察股息率 | 理想买入股息率 |
|---|---:|---:|
| 公用事业 / 运营商 | 4%+ | 4.5%-5.5% |
| 银行 | 5%+ | 5.5%-6.5% |
| 煤炭 / 资源 | 6%+ | 7%+ |
| 稳定消费红利 | 3%-4% | 4%+ |
| 港股红利 | 6%+ | 7%+ |

### 6.2 无风险利率锚

股息率必须高于：

```text
10 年期中国国债收益率 + 行业风险溢价
```

说明：

- 10 年期中国国债收益率作为动态无风险利率锚。
- 行业风险越高，要求的股息率越高。
- 港股、强周期、银行等资产需要更高风险补偿。

### 6.3 财报节点重估

- 三季报发布前，可基于上一年度分红和当年经营趋势估算股息率。
- 三季报发布后，必须重估当年可持续分红能力。
- 年报发布后，必须重新计算税后分红现金流与组合实际股息率。

### 6.4 股息率过低时的处理

若股价上涨导致动态可持续股息率低于 4%，则：

1. 停止新增入金；
2. 检查估值是否进入历史高位；
3. 检查是否存在更优替代资产；
4. 按核心仓/周期仓属性决定是否逐级减仓。

## 7. MA120 偏离度纪律

MA120 规则只作为价格纪律，不替代基本面判断。

### 7.1 高位停止买入

```text
If 标的价格 > MA120 x 1.12
Then 停止该标的定投，当月资金转入货币基金、国债逆回购或现金待命。
```

### 7.2 低位加仓评估

```text
If 标的价格 < MA120 x 0.88
Then 触发加仓评估，可动用此前积累的待命资金。
```

但必须同时满足：

- 股息率达标
- 现金流稳定
- 分红可持续
- 资产负债表未恶化
- 行业周期未进入明显下行拐点
- 单票和行业仓位未超限

### 7.3 禁止机械补仓

```text
If 只有价格便宜但基本面恶化
Then 不允许机械补仓。
```

### 7.4 大盘状态过滤器

| 情况 | 操作 |
|---|---|
| 个股跌破 0.88，但行业和公司基本面恶化 | 禁止补仓 |
| 个股跌破 0.88，行业无异常，现金流稳定 | 小额分批补 |
| 大盘系统性下跌，多个优质红利股同时跌破 0.88 | 允许组合级释放现金 |
| 个股跌破 0.88，同时分红预期下修 | 进入风险观察，不加仓 |

## 8. 加仓纪律

### 8.1 普通加仓

普通加仓只使用月度工资投入和当期分红复投资金。

条件：

- 股息率达到观察区
- 价格不高于 MA120 x 1.12
- 仓位未超限
- 基本面无恶化

### 8.2 低位加仓

低位加仓必须满足：

- 价格低于 MA120 x 0.88
- 股息率达到理想买入区
- 现金流稳定
- 分红可持续
- 仓位未超限

低位加仓必须分批，不允许一次性打满。

### 8.3 系统性下跌加仓

若大盘系统性下跌，且多个优质红利资产同时达标，可释放现金仓位。

释放节奏建议：

| 下跌环境 | 现金释放比例 |
|---|---:|
| 初次跌入低估区 | 释放现金的 25% |
| 多个核心资产股息率达标 | 再释放 25% |
| 财报验证现金流稳定 | 再释放 25% |
| 市场恐慌但基本面未坏 | 保留最后 25% 备用 |

### 8.4 禁止加仓情况

出现以下情况，不允许加仓：

- 单只股票达到仓位上限
- 单一行业达到仓位上限
- 分红不可持续
- 自由现金流无法覆盖分红
- 资产负债表恶化
- 行业处于周期利润顶部
- 股价下跌来自基本面恶化
- 组合现金仓位低于安全底线

---

## 9. 止盈与退出纪律

逐级止盈必须以股息率、估值和基本面共同触发，不能只因浮盈而卖出。

### 9.1 核心现金流仓：慢卖

核心仓只有在以下情况才考虑减仓：

- 股息率明显低于同类资产
- 估值进入历史高位
- 分红增速明显下降
- 未来现金流质量下降
- 有更好的替代资产
- 单票或行业被动超限过多

核心仓不因短期股价上涨机械卖出。

### 9.2 周期增强仓：快卖

周期仓适合严格执行股息率止盈。

参考阶梯：

| 可持续股息率变化 | 操作 |
|---|---|
| 从 5% 降至 4% | 可减持三分之一 |
| 从 4% 降至 3.5% | 可再减持三分之一 |
| 从 3.5% 降至 3% | 可再减持三分之一或完成退出 |

说明：

- 阈值必须按个股质量、行业周期和无风险利率调整。
- 强周期资产必须更快止盈。
- 核心现金流仓可以放宽止盈条件。

### 9.3 基本面退出

出现以下情况，应优先考虑退出或降级为观察：

- 分红大幅下调且无法解释为一次性因素
- 经营现金流连续恶化
- 自由现金流长期无法覆盖分红
- 资产负债率持续上升
- 行业长期逻辑改变
- 监管导致 ROE 中枢下降
- 公司治理风险暴露
- 分红政策明显转弱

**新增规则：分红覆盖率 / 自由现金流覆盖率连续恶化降级**

当一只红利标的在最近两次定期报告（例如连续两个半年报、或年报与次年半年报）中，出现以下情况之一：

- 分红覆盖率（经营活动现金流净额 / 分红总额）连续两个报告期下降；
- 自由现金流覆盖率（自由现金流 / 分红总额）连续两个报告期下降；

即使该标的当前股息率仍处于较高水平，也不得以此为由加仓。应立即将该标的从核心现金流仓或周期增强仓降级为观察仓，并优先复核：

1. 分红资金是否开始依赖借款或存量现金；
2. 资本开支是否已开始侵蚀可用于分红的自由现金流；
3. 行业周期是否已从稳定期转入下行期。

在覆盖率连续两个报告期企稳回升之前，该标的不得恢复为核心仓，只允许小仓位观察。

## 10. 市赚率 PR 辅助估值

市赚率只作为辅助估值工具，不得替代现金流与分红可持续性判断。

### 10.1 基础公式

```text
PR = PE / ROE / 100
```

### 10.2 修正公式

```text
PR = N * PE / ROE / 100
```

### 10.3 修正系数

| 股利支付率 | N 值 |
|---|---:|
| 股利支付率 > 50% | N = 1 |
| 股利支付率 < 25% | N = 2 |
| 股利支付率 25%-50% | N 按比例调整 |

### 10.4 使用限制

| 类型 | PR 适用性 |
|---|---|
| 稳定盈利消费 / 运营商 | 可用 |
| 银行 | 只能辅助，需结合净息差、不良率、拨备覆盖率 |
| 煤炭 / 资源 | 谨慎使用，必须用周期均值利润 |
| 电力 / 公用事业 | 结合资本开支、负债率、ROIC |
| 交运 | 结合周期位置和运价趋势 |

PR 处于 0.4-0.5 区间时，可进入“低价买优质资产”的候选评估区。  
但仍需通过股息率、现金流、负债和行业周期校验。

## 11. 港股红利资产额外约束

若纳入港股红利资产，必须单独评估税务、汇率、流动性和估值折价。

### 11.1 港股额外风险

- 港股分红税务和 A 股不同，不能套用 A 股持股一年免税逻辑。
- 港币兑人民币存在汇率波动。
- 港股高股息资产可能长期处于估值折价状态。
- 港股流动性和投资者结构与 A 股不同。
- A/H 两地上市公司应比较 A/H 溢价和税后股息率。

### 11.2 港股仓位约束

港股红利资产合计原则上不超过境内红利池的 **20%-30%**。

若港股资产超过 30%，必须建立单独的港股子框架。

---

## 12. 红利陷阱排除清单

出现以下任一情况，即使股息率很高，也不得直接买入。

| 风险信号 | 解释 |
|---|---|
| 分红超过自由现金流 | 可能靠借钱或消耗现金分红 |
| 经营现金流连续恶化 | 利润可能只是会计利润 |
| 资产负债率持续上升 | 未来分红空间受压 |
| 大额资本开支周期刚开始 | 现金流可能被 CAPEX 吃掉 |
| 行业处于周期利润顶部 | 高股息可能不可持续 |
| 一次性收益支撑净利润 | 分红基础不稳定 |
| 大股东高比例质押 | 存在治理和流动性风险 |
| 应收账款异常上升 | 利润质量下降 |
| 分红政策突然大幅变化 | 需要重新评估股东回报纪律 |
| 监管政策可能压低 ROE | 银行、公用事业尤其要注意 |

核心原则：

> 高股息不是买入理由，可持续高股息才是买入理由。

## 13. If-Then 执行纪律

```text
If 股息率进入历史高分位且现金流稳定
Then 允许进入观察区，但仍需等待价格、估值和仓位共同满足。
```

```text
If 股息率升高主要来自股价暴跌
Then 必须先判断基本面是否恶化，不得机械补仓。
```

```text
If 分红率超过经营现金流承受能力
Then 将高股息标记为不可持续，不允许按现金流资产处理。
```

```text
If 分红超过自由现金流覆盖能力且资产负债表杠杆上升
Then 标记为股息陷阱，禁止仅凭高股息率买入。
```

```text
If 大盘系统性下跌且标的跌破长期风险线
Then 只允许小仓位分批，不允许情绪性一次性打满。
```

```text
If 标的已经达到单一资产仓位上限
Then 即使股息率吸引，也只能给出观察或调仓建议。
```

```text
If 境内股权激励、奖金或打新收益到账
Then 优先沉淀为 A 股红利池待命资金，不跨境转出。
```

```text
If 核心现金流仓股息率下降但基本面继续改善
Then 不机械止盈，先比较替代资产收益率。
```

```text
If 周期增强仓股息率下降且估值修复完成
Then 分批止盈，将资金转回核心现金流仓或现金待命仓。
```

## 14. 税务与记录

### 14.1 A 股分红税务原则

A 股分红税务与持股期限有关。执行层面应遵守以下原则：

- 长期持有优先，尽量减少短期换仓导致的税务摩擦。
- 分红到账后记录税前金额、税后金额、到账日期和持股期限。
- 对高频调仓、短期持有获得的分红，必须考虑税后收益率下降。

### 14.2 港股税务原则

港股分红税务与 A 股不同，不能直接套用 A 股规则。

必须记录：

- 税前分红
- 扣税金额
- 税后到账
- 汇率变化
- 港币/人民币折算收益

### 14.3 必须保存的数据

每个标的必须保存：

- 买入日期
- 买入价格
- 买入金额
- 当前价格
- 当前仓位占比
- 分红记录
- 税后到账金额
- 复投记录
- 减仓记录
- 财报复盘结论

## 17. 年度复盘机制

本框架不需要频繁交易，但必须年度复盘。

每年年报后执行一次组合级复盘。

### 17.1 年度复盘问题

1. 组合实际股息率是多少？
2. 税后到账现金流是多少？
3. 分红增长率是多少？
4. 哪些标的分红下修？
5. 哪些标的自由现金流不足以覆盖分红？
6. 哪些行业仓位过重？
7. 单只股票是否超过上限？
8. 强周期资产是否超过上限？
9. 港股资产是否超过上限？
10. 2036 年现金流目标是否提前或滞后？
11. 是否需要把某些周期仓利润转入核心仓？
12. 下一年度工资投入节奏是否调整？

### 17.2 年度复盘动作

| 复盘结果 | 动作 |
|---|---|
| 分红稳定，估值合理，仓位未超限 | 继续持有并复投 |
| 分红稳定，但估值过高 | 暂停新增买入 |
| 分红下修，但现金流仍稳定 | 降级观察 |
| 分红下修且现金流恶化 | 减仓或剔除 |
| 周期仓估值修复完成 | 分批转入核心仓或现金 |
| 行业仓位超限 | 暂停该行业新增买入 |

## 18. 禁止事项清单

本框架禁止以下行为：

- 因为股息率高而无视现金流恶化。
- 因为股价大跌而机械补仓。
- 因为低 PE、低 PB 就认定便宜。
- 把周期顶部利润当作长期分红能力。
- 单一行业过度集中。
- 单一标的过度集中。
- 为了追求高股息买入治理风险明显的公司。
- 用 A 股红利池资金补贴美股账户。
- 在未复盘财报前重仓加码。
- 把 9%-10% 年化当作保证收益。

## 19. 框架总原则

### 19.1 战略原则

> 用长期工资结余和分红复投，持续买入可验证、可持续、可穿越周期的人民币现金流资产。

### 19.2 执行原则

> 先判断现金流，再判断股息率；先判断仓位，再判断价格；先排除红利陷阱，再讨论买入机会。

### 19.3 风控原则

> 宁可错过一次高股息机会，也不能让境内生活保底资金池变成单行业、单标的、强周期押注。

### 19.4 终局目标

> 到 2036 年，建立一套分散、低换手、可解释、可持续的人民币现金流组合，为国内生活、家庭责任和长期安全感提供底盘。

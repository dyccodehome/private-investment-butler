# CN_Dividend_Income A 股红利现金流框架

## 适用范围

本子框架只处理 A 股和港股中以分红、股息率、低估值、防守现金流为核心的标的。典型行业包括银行、煤炭、电力、公用事业、运营商、交运和稳定消费现金流资产。

## 核心判断维度

- 股息率必须来自可持续经营现金流，而不是一次性处置收益或周期顶部利润。
- 分红稳定性优先于单年高股息率，至少关注过去三到五年的分红连续性。
- 估值必须和盈利质量一起判断，不能只看低 PE、低 PB。
- 资产负债表要稳健，重点关注有息负债、资本开支压力和监管约束。
- 行业周期位置必须被显式讨论，尤其是煤炭、资源和强周期红利资产。

## If-Then 纪律

- If 股息率进入历史高分位且现金流稳定，Then 允许进入观察区，但仍需等待价格、估值和仓位共同满足。
- If 股息率升高主要来自股价暴跌，Then 必须先判断基本面是否恶化，不得机械补仓。
- If 分红率超过经营现金流承受能力，Then 将高股息标记为不可持续，不允许按现金流资产处理。
- If 大盘系统性下跌且标的跌破长期风险线，Then 只允许小仓位分批，不允许情绪性一次性打满。
- If 标的已经达到单一资产仓位上限，Then 即使股息率吸引，也只能给出观察或调仓建议。

## 必须申请的数据

- 最新价格、估值、股息率和历史分红。
- 最近财报中的经营现金流、净利润、资本开支和负债变化。
- 历史交易或持仓记录，避免重复补仓导致集中度失控。

## 输出要求

每次输出必须明确回答：现金流是否可持续、估值是否足够便宜、仓位是否允许继续增加、最坏情况下的回撤和分红下修风险。

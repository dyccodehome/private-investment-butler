# US_Income_Options 美股收益期权框架

## 适用范围

本子框架只处理美股和美元资产中的股息收入、Covered Call、Cash Secured Put、权利金收入和现金管理问题。它服务于现金流，不服务于短线方向赌博。

## 核心判断维度

- 权利金不是无风险收益，必须同时展示最大亏损、保证金占用和被行权后的持仓后果。
- Covered Call 只能在愿意按执行价卖出正股时使用。
- Cash Secured Put 只能在愿意按执行价买入正股且现金足额覆盖时使用。
- 隐含波动率必须和财报、宏观事件、监管风险一起判断，不能只因 IV 高就卖期权。
- 标的质量优先于权利金厚度，禁止为高 Premium 接受无法长期持有的底层资产。

## If-Then 纪律

- If 用户想卖 Put，Then 必须检查现金覆盖、目标买入价、最大亏损和被行权后的组合集中度。
- If 用户想卖 Covered Call，Then 必须检查持有正股数量、执行价是否符合卖出意愿、潜在踏空成本。
- If 标的即将发布财报或重大事件，Then 默认降低合约规模或等待事件落地，不允许无保护扩大仓位。
- If IV 高但基本面恶化，Then 不得把风险补偿误判为便宜权利金。
- If 期权操作会导致保证金压力或裸卖暴露，Then 必须触发拒绝或人工确认。

## 必须申请的数据

- 标的最新价格、波动率环境、期权链关键行权价和到期日。
- 持仓、现金余额、保证金占用和历史期权交易记录。
- 财报日期、重大新闻和市场风险事件。

## 输出要求

每次输出必须明确回答：该操作赚的是什么钱、承担的最大损失是什么、被行权后是否愿意持有或卖出、是否违反现金覆盖和仓位纪律。
